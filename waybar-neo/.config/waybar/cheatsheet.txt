MANGO — OPERATOR COMMAND REFERENCE
════════════════════════════════════════════════════════
PRESS ALT + H TO SHOW | ESC TO HIDE
Source: mango/cfg/keybinds.conf
SUPER = Windows / logo key

APPLICATIONS

ALT + T                  Kitty terminal
ALT + E                  Thunar file explorer
ALT + B                  Firefox browser
ALT + SPACE              Tofi application launcher
ALT + F                  Fuzzel application launcher
ALT + X                  Geany
ALT + H                  Keyboard reference


WINDOW CONTROL

ALT + Q                  Close window
ALT + TAB                Next window

ALT + ←                  Focus left
ALT + →                  Focus right
ALT + ↑                  Focus up
ALT + ↓                  Focus down

ALT + SHIFT + ←          Swap window left
ALT + SHIFT + →          Swap window right
ALT + SHIFT + ↑          Swap window up
ALT + SHIFT + ↓          Swap window down


WINDOW STATE

ALT + G                  Toggle global
ALT + TAB                Overview
ALT + F                  Toggle floating
ALT + SHIFT + F          Fullscreen
ALT + Z                  Scratchpad


LAYOUT

SUPER + SHIFT + X          Scroller width 100%
ALT + SHIFT + T          Set tiling layout
ALT + SHIFT + S          Set scrolling layout
ALT + SHIFT + C          Set center tile layout
ALT + SHIFT + N          Switch layout


WORKSPACES

ALT + 1..9               Switch to workspace
ALT + SHIFT + 1..9       Move window to workspace and follow

GAPS

SUPER + ALT + X            Increase gaps by 1
SUPER + ALT + Z            Decrease gaps by 1
SUPER + ALT + R            Toggle gaps


FLOATING WINDOW POSITION

CTRL + SHIFT + ↑           Move up 50 px
CTRL + SHIFT + ↓           Move down 50 px
CTRL + SHIFT + ←           Move left 50 px
CTRL + SHIFT + →           Move right 50 px


FLOATING WINDOW SIZE

CTRL + ALT + ↑             Shrink vertically 50 px
CTRL + ALT + ↓             Grow vertically 50 px
CTRL + ALT + ←             Shrink horizontally 50 px
CTRL + ALT + →             Grow horizontally 50 px


SCREEN CAPTURE

PRINT                      Capture full screen
CTRL + PRINT               Capture selected region

Saved to ~/Pictures/Screenshots


AUDIO

VOLUME UP                  Volume +5%
VOLUME DOWN                Volume -5%
MUTE                       Toggle output mute
SHIFT + MUTE               Toggle microphone mute


DISPLAY

BRIGHTNESS UP              Brightness +2%
BRIGHTNESS DOWN            Brightness -2%
SHIFT + BRIGHTNESS UP      Brightness 100%
SHIFT + BRIGHTNESS DOWN    Brightness 1%


NOTIFICATIONS

SUPER + N                  Toggle notification center


SYSTEM

ALT + L                    Lock screen
SUPER + L                  Lock screen
SUPER + O                  Fuzzel power menu
SUPER + R                  Reload Mango configuration
ALT + R                    Reload Mango configuration
CTRL + ALT + RETURN        Emergency terminal (Ghostty)


MOUSE

SUPER + LEFT BUTTON        Move window
SUPER + RIGHT BUTTON       Resize window
MIDDLE BUTTON              Toggle maximize


TOUCHPAD

3-FINGER LEFT              Workspace right
3-FINGER RIGHT             Workspace left
4-FINGER UP                Overview


════════════════════════════════════════════════════════

ESC                        CLOSE REFERENCE
